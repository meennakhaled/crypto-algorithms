# Crypto Algorithms 🔐

This repository contains implementations of fundamental **Cryptography Algorithms** using **Java**.  
The project is designed for learning and demonstrating how classic encryption systems work through practical implementations.

---

##  Included Algorithms

###  AES with GUI
- Advanced Encryption Standard (AES)
- Graphical User Interface built with Java
- Encrypt and decrypt text

###  DES
- Data Encryption Standard (DES)
- Symmetric encryption implementation

###  LFSR
- Linear Feedback Shift Register
- Pseudo-random sequence generation

###  RSA
- Public-key cryptography algorithm
- Key generation, encryption, and decryption

## Technologies Used

- Java
- Cryptography Concepts
